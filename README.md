# LLM Dataist
AI agent to help you analyze CSV

**Installation and Setup**

Clone the repo:
git clone <repository-url>
cd dataist

Install dependencies:
pyproject.toml -> dependencies

Create .env file based on .env.example and configure environment variables.

chainlit run app.py
